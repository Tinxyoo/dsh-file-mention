功能

两种引用方式，一种操作习惯

文件与内容都走输入框原本的引用语法，不引入新的概念。

右键文件，直接引用

文件树里任意文件右键「添加到输入框」，插入带文件图标的原子 chip。点击 chip 可以立即打开预览。

选中内容，一键引用

在 Markdown、代码或纯文本预览里选中一段内容，选区上方会浮出「引用到输入框」，点击即插入引用卡片。

整块删除，不留碎片

chip 和引用卡片都是原子节点：光标移到旁边，退格一次整块消失，不会一个字一个字地删。

安装

三步装上，不用构建

前提：运行的是 DeepSeek Harness 的 Web / Desktop 界面，profile 可写。本地目录安装是链接引用，装好后别移动源目录。

获取插件目录

克隆仓库，或下载后解压到本机任意位置。

git clone https://github.com/Tinxyoo/dsh-file-mention.git

打开「插件 → 添加插件」

在包名/路径输入框里填仓库地址，或填本地目录的绝对路径。

https://github.com/Tinxyoo/dsh-file-mention

安装并启用

安装完成后点 Enable now；若提示需要重启，重启 DSH 即可。

也可以让 agent 安装：把目录放好后说「安装 <绝对路径> 这个插件」，它会调用 plugin_manager install_bundle。

使用

装上之后怎么用

引用使用与 @ 文件选择器相同的语法：路径相对工作区根目录，含空格时写成 @"my file.md"。

引用文件

  1. 1打开右侧文件树（files 页，或文件预览旁的文件树）
  2. 2右键任意文件
  3. 3选择 添加到输入框
  4. 4输入框出现文件 chip；点击可预览，退格 一次整块删除

引用内容

  1. 1在右侧文件预览里选中一段内容
  2. 2选区上方出现 引用到输入框
  3. 3点击，输入框插入一张引用卡片
  4. 4紧接着写你的问题即可

从末尾删除时，第一次退格会先删掉引用自动补的分隔空格，第二次整块删除——这是输入框对引用节点的统一行为。

兼容性

能跑在哪，边界在哪

插件只使用用户已有的公开槽位与输入框能力，不引入运行时依赖。

DeepSeek Harness 版本面向 0.2.2-rc.1 一代的 Web 组合开发；宿主接缝变化时可能需要小改
平台Web / Desktop（Client 插件，纯 CLI 会话看不到效果）
内容引用范围Markdown、代码、纯文本预览；PDF / Office 文本层暂未接入
构建 / 依赖无构建步骤，无第三方运行时依赖
安装形态本地目录为 link: 引用：源目录被删或移动，插件会失效
